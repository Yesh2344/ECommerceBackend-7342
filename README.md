## Overview

ECommerceBackend is a production‑ready, asynchronous FastAPI service that provides:

* Product catalog (stubbed for demo)
* Shopping‑cart management (add, remove, list)
* Mock payment processing (Stripe‑compatible interface)
* Centralised configuration via environment variables
* Structured logging, error handling and type‑safe models
* Full test suite with `pytest`

The project follows modern Python best practices: **type hints**, **pydantic** for data validation, **SQLAlchemy 2** for ORM, and a clean layered architecture.
